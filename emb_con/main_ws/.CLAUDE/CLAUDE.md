# 机器人工程
- 这是一个实现数个任务的，通过上位机和单片机进行控制的机器人工程
- 这个工作空间用来存放单片机（STM32H723ZGT6）的代码

## 任务
机器人一共要完成三个任务
1. 从启动区移动到指定位置，该位置有一个三个方块（每个边长35cm, 650g左右）竖向堆叠的“塔”， 机器人要在不推倒塔的情况下把最上方的方块上下翻转180°
2. 完成任务1后要经过一个高低不一的四平台（高的距离地面20cm，低的距离地面40cm），有三个相同颜色和一个不同颜色的方块，识别出需要取的三个颜色相同的方块，经过一个15°，水平1.5m的向上斜坡把方块运送到斜坡上的地面
3. 把运送后的方块堆叠成一个竖向放置的塔

## 机器人机构
1. 主控
    - 迷你主机
    - STM32F723ZGT6
2. 底盘
    - 麦克纳姆轮*4
    - DJI M3085\*4 + c620电调\*4(CAN控制)
3. 机械臂
    - 可伸缩升降的机械臂*2
    - M3508电机*4控制伸缩升降
